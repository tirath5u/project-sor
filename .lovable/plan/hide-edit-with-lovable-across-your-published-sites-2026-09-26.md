# Hide “Edit with Lovable” across your published sites

## What is already confirmed
- This SOR project's **Hide Lovable badge** setting is already on, and the project is published publicly. No code change or republishing is needed for this setting here.
- Lovable's setting applies to each published project separately. There is no account-wide switch. The badge may still appear inside the editor or preview, even when hidden from the live site.

## Plan
1. Check the live SOR address and custom domain to distinguish a live badge from one shown only in preview. If it appears on the live site despite the enabled setting, investigate that discrepancy rather than adding fragile CSS to hide it.
2. For your other accessible projects, **myproject-hub** and **COD Hub 26-27**, turn on **Hide Lovable badge** separately in each project's **Project settings → Publishing**, if it is not already on. The current project's publishing control cannot change a different project's setting, so those projects need to be opened individually.
3. Verify each published address without the badge. No changes to calculators, content, or access settings.

## Limitations
- The setting requires a Pro plan or higher. If the plan is downgraded, the badge can return on the next publish.
- This does not remove Lovable's own editor or preview controls; it governs the badge on published websites. Future projects also need this setting enabled individually.
